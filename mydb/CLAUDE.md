## 기술 스택

- 포트폴리오 자체는 HTML/CSS/JS 또는 간단한 프레임워크로 구성

## 프로젝트 섹션

- 현재 등록된 프로젝트 없음
- 추후 프로젝트 추가 예정 — 섹션은 미리 구성해 둘 것

## 디자인 방향

- 깔끔하고 세련된 스타일
- 미니멀한 레이아웃
- 컬러: 흰색/밝은 배경 or 다크모드 기반 중 선택 여지 있음
- 폰트: 가독성 좋은 산세리프 계열

2. About — 전공, 관심 분야(사이버보안)
